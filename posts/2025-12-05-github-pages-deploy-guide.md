## 为什么选 GitHub Pages

GitHub Pages 对个人项目完全免费，没有服务器要维护，没有账单要担心。只要项目是纯静态的 HTML/CSS/JS，就可以直接托管。

## 仓库结构

最简单的做法是把静态文件放在仓库根目录，或者放进 `docs/` 目录。我个人更喜欢用 `docs/`，这样仓库根目录还能放 README 和其他说明文件，不会混在一起。

## 开启 Pages

1. 打开仓库的 Settings
2. 找到 Pages 一栏
3. 选择分支和目录（比如 `main` 分支 + `/docs`）
4. 保存，等一两分钟，链接就会生成

## 自定义域名（可选）

如果有自己的域名，只需要在仓库根目录加一个 `CNAME` 文件，写上域名，再去域名服务商那边加一条 CNAME 记录指向 `<用户名>.github.io`。

## 关于路由

纯前端 SPA 在 GitHub Pages 上跑，需要注意它不支持服务器端的路径重写。用 hash 路由（`#/xxx`）是最省心的方式，不需要额外配置 404 页面。
