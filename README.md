# Henry's Blog

个人技术博客，记录技术学习、项目经验与生活思考。

🌐 **在线访问**: [https://heyuanyou.github.io/blog/](https://heyuanyou.github.io/blog/)

## 📖 关于

这是一个基于 [Hugo](https://gohugo.io/) 静态网站生成器构建的个人博客，使用 [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 主题。

## 🚀 本地启动

1. 启动开发服务器
```bash
hugo server
```

2. 访问 http://localhost:1313/blog/ 查看博客

### 构建静态网站

```bash
hugo
```

构建后的文件将生成在 `docs/` 目录中。
