Kafka 核心面试题：深度与广度解析

🚀 Apache Kafka 核心面试题深度解析 本文整理了一系列覆盖 Kafka 基础、架构、运维和高级特性的面试问题，旨在帮助您全面掌握这一流行的分布式流处理平台。 一、基础与核心概念 (Basics and Core Concepts) 1. 什么是 Kafka？它解决了什么问题？ 答案要点： Kafka 是一个分布式流处理平台，最初由 LinkedIn 开发，后贡献给 Apache 基金会。 它主要用于处理实时数据流，具备高吞吐量、持久性、水平扩展性、容错性和低延迟的特点。 解决的问题： 解耦 生产者和消费者。 削峰填谷，平衡流量。 持久化存储 消息，支持离线处理和回溯。 构建实时数据管道和流式应用。 2. Kafka 中的 Topic、Partition、Offset 分别是什么？它们之间的关系是什么？ 答案要点： Topic (主题)： 一种逻辑上的概念，代表一类消息流。生产者将消息发布到特定的 Topic。 Partition (分区)： Topic 在物理上被分成一个或多个分区。这是 Kafka 并行处理和扩展的基础。消息在分区内有序。 Offset (位移)： 分区内每条消息的唯一标识符（一个递增的整数）。消费者通过记录和提交 Offset 来跟踪已消费的消息。 关系： 一个 Topic 由多个 Partition 组成，每个 Partition 内部的消息都有一个单调递增的 Offset。 3. 请解释 Kafka 的生产者（Producer）发送消息时的负载均衡机制。 答案要点： 生产者发送消息到 Topic 时，会根据以下逻辑选择目标 Partition： 指定 Partition： 如果消息指定了 Partition，则直接发送到该分区。 指定 Key： 如果消息指定了 Key 但未指定 Partition，则使用 Key 的哈希值（hash(key) % num_partitions）来确定 Partition，确保相同 Key 的消息总是发送到同一分区，实现消息的局部有序。 无 Key 无 Partition： 采用轮询（Round-Robin）方式，将消息均匀分配到所有可用分区，实现负载均衡。 二、架构与组件 (Architecture and Components) 4. 简述 Kafka 的高可用性和容错性是如何实现的？ 答案要点： ...
