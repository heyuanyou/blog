基础概念#

1. 什么是 Rust？它有哪些特点？#

答案：

Rust 是由 Mozilla 开发的系统级编程语言，于 2010 年首次发布，2015 年发布 1.0 版本。

核心特点：

  • 内存安全：编译时保证内存安全，无需垃圾回收
  • 零成本抽象：高级抽象不带来运行时开销
  • 并发安全：编译时防止数据竞争
  • 性能优异：接近 C/C++ 的性能
  • 类型系统强大：类型推断、模式匹配、代数数据类型
  • 工具链完善：Cargo 包管理器、rustfmt、clippy 等

设计目标：

  • 在保证内存安全的同时提供系统级性能
  • 通过类型系统在编译时捕获错误
  • 提供现代化的开发体验

2. Rust 的编译过程是什么？#

答案：

编译流程：

Rust 源码 → 词法分析 → 语法分析 → 类型检查 → 借用检查 → MIR 生成 → LLVM IR → 机器码

编译命令：

# 编译
rustc main.rs

# 使用 Cargo 构建
cargo build

# 运行
cargo run

# 发布构建（优化）
cargo build --release

编译特点：

  • 严格检查：编译时进行所有权、借用、生命周期检查
  • 增量编译：只重新编译变更的模块
  • 交叉编译：支持多平台编译
  • 链接优化：静态链接，生成独立可执行文件

3. Rust 的包管理系统 Cargo 是什么？#

答案：

Cargo 是 Rust 的官方包管理器和构建工具。

主要功能：

  • 依赖管理：Cargo.toml 管理项目依赖
  • 构建系统：自动编译和链接
  • 测试框架：内置测试支持
  • 文档生成：cargo doc 生成文档
  • 代码格式化：cargo fmt 格式化代码
  • 代码检查：cargo clippy 静态分析

项目结构：

project/
├── Cargo.toml      # 项目配置和依赖
├── Cargo.lock      # 依赖版本锁定
└── src/
    └── main.rs     # 源代码

示例 Cargo.toml：

[package]
name = "my_project"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = "1.0"
tokio = { version = "1.0", features = ["full"] }

所有权系统#

4. 什么是所有权（Ownership）？#

答案：

所有权是 Rust 的核心特性，用于在编译时保证内存安全，无需垃圾回收。

所有权规则：

  1. 每个值都有一个所有者
  2. 同一时间只能有一个所有者
  3. 所有者离开作用域时，值被丢弃

示例：

fn main() {
    let s = String::from("hello");  // s 拥有字符串
    takes_ownership(s);              // s 的所有权移动到函数
    // println!("{}", s);           // 错误！s 不再有效
}

fn takes_ownership(some_string: String) {
    println!("{}", some_string);
} // some_string 离开作用域，内存被释放

5. 移动（Move）和复制（Copy）的区别？#

答案：

移动（Move）：

  • 所有权转移，原变量不再可用
  • 适用于堆分配的数据（String、Vec 等）

复制（Copy）：

  • 值被复制，原变量仍可用
  • 适用于栈上的简单类型（i32、bool、char 等）

示例：

// Copy trait 类型
let x = 5;
let y = x;        // 复制，x 仍可用
println!("{}", x); // OK

// Move 类型
let s1 = String::from("hello");
let s2 = s1;      // 移动，s1 不再可用
// println!("{}", s1); // 错误！s1 已被移动

实现 Copy trait：

#[derive(Copy, Clone)]
struct Point {
    x: i32,
    y: i32,
}

6. 什么是借用（Borrowing）？#

答案：

借用允许在不获取所有权的情况下使用值，通过引用实现。

借用规则：

  1. 不可变引用可以有多个
  2. 可变引用只能有一个
  3. 可变引用和不可变引用不能同时存在

示例：

fn main() {
    let s = String::from("hello");
    
    // 不可变借用
    let len = calculate_length(&s);
    println!("The length of '{}' is {}.", s, len); // s 仍可用
    
    // 可变借用
    let mut s = String::from("hello");
    change(&mut s);
    println!("{}", s);
}

fn calculate_length(s: &String) -> usize {
    s.len()
} // s 离开作用域，但因为它没有所有权，所以不会释放

fn change(some_string: &mut String) {
    some_string.push_str(", world");
}

7. 悬垂引用（Dangling References）是什么？#

答案：

悬垂引用是指引用指向的内存已经被释放。

Rust 如何防止：

编译器会在编译时检查，确保引用在数据有效期间保持有效。

错误示例：

fn main() {
    let reference_to_nothing = dangle(); // 编译错误
}

fn dangle() -> &String {  // 错误：返回悬垂引用
    let s = String::from("hello");
    &s  // s 离开作用域，内存被释放
}

正确做法：

fn no_dangle() -> String {
    let s = String::from("hello");
    s  // 返回所有权
}

借用与引用#

8. 可变引用和不可变引用的区别？#

答案：

不可变引用（&T）：

  • 可以同时有多个
  • 不能修改数据
  • 用于只读访问

可变引用（&mut T）：

  • 同一时间只能有一个
  • 可以修改数据
  • 不能与不可变引用共存

示例：

let mut s = String::from("hello");

let r1 = &s;      // 不可变引用，OK
let r2 = &s;      // 不可变引用，OK
// let r3 = &mut s; // 错误！不能同时有可变和不可变引用

let r3 = &mut s;  // 可变引用，OK
// let r4 = &mut s; // 错误！不能同时有两个可变引用

9. 什么是借用检查器（Borrow Checker）？#

答案：

借用检查器是 Rust 编译器的核心组件，在编译时检查所有权的使用是否正确。

检查内容：

  • 所有权是否正确转移
  • 引用是否有效
  • 是否存在数据竞争
  • 是否存在悬垂引用

示例：

fn main() {
    let mut v = vec![1, 2, 3];
    let first = &v[0];        // 不可变借用
    v.push(4);                // 错误！尝试可变借用
    println!("{}", first);    // first 仍在使用
}

为什么这样设计：

  • 防止数据竞争
  • 保证内存安全
  • 无需运行时检查

生命周期#

10. 什么是生命周期（Lifetime）？#

答案：

生命周期是 Rust 中引用有效的作用域，用于确保引用在使用期间有效。

生命周期标注语法：

&i32        // 引用
&'a i32     // 带有生命周期标注的引用
&'a mut i32 // 带有生命周期标注的可变引用

示例：

fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}

11. 生命周期省略规则是什么？#

答案：

Rust 编译器在某些情况下可以自动推断生命周期，称为生命周期省略。

三条规则：

  1. 每个引用参数都有自己的生命周期
  2. 如果只有一个输入生命周期，它被赋给所有输出生命周期
  3. 如果是方法且有 &self 或 &mut self，self 的生命周期被赋给所有输出生命周期

示例：

// 规则 1
fn first_word(s: &str) -> &str { ... }
// 展开为：
fn first_word<'a>(s: &'a str) -> &'a str { ... }

// 规则 2
fn longest(x: &str, y: &str) -> &str { ... }
// 不适用，需要显式标注

// 规则 3
impl<'a> ImportantExcerpt<'a> {
    fn announce_and_return_part(&self, announcement: &str) -> &str {
        // self 的生命周期被赋给返回值
        println!("Attention! {}", announcement);
        self.part
    }
}

12. 静态生命周期 ‘static 是什么？#

答案：

'static 生命周期表示引用在整个程序运行期间都有效。

常见场景：

  • 字符串字面量
  • 全局变量
  • 常量

示例：

let s: &'static str = "I have a static lifetime.";

// 函数签名
fn print_static(s: &'static str) {
    println!("{}", s);
}

注意：

  • 不要过度使用 'static
  • 大多数情况下应该使用具体的生命周期参数

类型系统#

13. Rust 有哪些基本数据类型？#

答案：

标量类型（Scalar Types）：

  • 整数：i8, i16, i32, i64, i128, isize / u8, u16, u32, u64, u128, usize
  • 浮点数：f32, f64
  • 布尔：bool
  • 字符：char（4 字节 Unicode）

复合类型（Compound Types）：

  • 元组：(i32, f64, u8)
  • 数组：[i32; 5]（固定长度）
  • 切片：&[T]（动态长度）

示例：

// 整数
let x: i32 = 42;
let y: u64 = 100;

// 浮点数
let z: f64 = 3.14;

// 布尔
let is_true: bool = true;

// 字符
let c: char = '中';

// 元组
let tup: (i32, f64, u8) = (500, 6.4, 1);
let (x, y, z) = tup;

// 数组
let arr: [i32; 5] = [1, 2, 3, 4, 5];
let first = arr[0];

14. 什么是 Option 和 Result？#

答案：

Option：

表示值可能存在或不存在，用于处理空值。

enum Option<T> {
    Some(T),
    None,
}

使用示例：

fn find_item(items: &[i32], target: i32) -> Option<usize> {
    for (index, &item) in items.iter().enumerate() {
        if item == target {
            return Some(index);
        }
    }
    None
}

// 使用
match find_item(&[1, 2, 3], 2) {
    Some(index) => println!("Found at index {}", index),
    None => println!("Not found"),
}

// 使用 unwrap（不推荐，会 panic）
let index = find_item(&[1, 2, 3], 2).unwrap();

// 使用 unwrap_or
let index = find_item(&[1, 2, 3], 5).unwrap_or(0);

// 使用 if let
if let Some(index) = find_item(&[1, 2, 3], 2) {
    println!("Found at {}", index);
}

Result<T, E>：

表示操作可能成功或失败，用于错误处理。

enum Result<T, E> {
    Ok(T),
    Err(E),
}

使用示例：

use std::fs::File;
use std::io::Error;

fn open_file(filename: &str) -> Result<File, Error> {
    File::open(filename)
}

// 使用 match
match open_file("hello.txt") {
    Ok(file) => println!("File opened successfully"),
    Err(e) => println!("Error: {}", e),
}

// 使用 unwrap（会 panic）
let file = File::open("hello.txt").unwrap();

// 使用 expect（带错误消息）
let file = File::open("hello.txt").expect("Failed to open file");

// 使用 ? 操作符（传播错误）
fn read_file() -> Result<String, std::io::Error> {
    let mut file = File::open("hello.txt")?;
    let mut contents = String::new();
    file.read_to_string(&mut contents)?;
    Ok(contents)
}

15. 什么是泛型（Generics）？#

答案：

泛型允许编写可重用的代码，适用于多种类型。

函数泛型：

fn largest<T: PartialOrd + Copy>(list: &[T]) -> T {
    let mut largest = list[0];
    for &item in list {
        if item > largest {
            largest = item;
        }
    }
    largest
}

结构体泛型：

struct Point<T> {
    x: T,
    y: T,
}

let integer = Point { x: 5, y: 10 };
let float = Point { x: 1.0, y: 4.0 };

枚举泛型：

enum Option<T> {
    Some(T),
    None,
}

enum Result<T, E> {
    Ok(T),
    Err(E),
}

方法泛型：

impl<T> Point<T> {
    fn x(&self) -> &T {
        &self.x
    }
}

// 为特定类型实现方法
impl Point<f32> {
    fn distance_from_origin(&self) -> f32 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}

16. 什么是 Trait？#

答案：

Trait 定义了一组方法签名，用于定义共享行为，类似于其他语言中的接口。

定义 Trait：

pub trait Summary {
    fn summarize(&self) -> String;
    
    // 默认实现
    fn summarize_author(&self) -> String {
        String::from("(Read more...)")
    }
}

实现 Trait：

pub struct NewsArticle {
    pub headline: String,
    pub location: String,
    pub author: String,
    pub content: String,
}

impl Summary for NewsArticle {
    fn summarize(&self) -> String {
        format!("{}, by {} ({})", self.headline, self.author, self.location)
    }
}

Trait 作为参数：

// 使用 impl Trait
pub fn notify(item: impl Summary) {
    println!("Breaking news! {}", item.summarize());
}

// 使用 Trait Bound
pub fn notify<T: Summary>(item: T) {
    println!("Breaking news! {}", item.summarize());
}

// 多个 Trait Bound
pub fn notify(item: impl Summary + Display) {}

// 使用 where 子句
fn some_function<T, U>(t: T, u: U) -> i32
where
    T: Display + Clone,
    U: Clone + Debug,
{
    // ...
}

返回实现 Trait 的类型：

fn returns_summarizable() -> impl Summary {
    NewsArticle {
        headline: String::from("Penguins win the Stanley Cup Championship!"),
        location: String::from("Pittsburgh, PA, USA"),
        author: String::from("Iceburgh"),
        content: String::from("The Pittsburgh Penguins once again are the best hockey team in the NHL."),
    }
}

错误处理#

17. Rust 的错误处理机制是什么？#

答案：

Rust 使用 Result<T, E> 进行错误处理，分为可恢复错误和不可恢复错误。

可恢复错误：Result<T, E>

use std::fs::File;
use std::io::ErrorKind;

fn open_file(filename: &str) -> Result<File, std::io::Error> {
    match File::open(filename) {
        Ok(file) => Ok(file),
        Err(error) => match error.kind() {
            ErrorKind::NotFound => {
                File::create(filename)
            }
            other_error => {
                Err(other_error)
            }
        }
    }
}

不可恢复错误：panic!

// 直接 panic
panic!("crash and burn");

// 通过索引越界触发
let v = vec![1, 2, 3];
v[99]; // panic!

错误传播：? 操作符

use std::fs::File;
use std::io::{self, Read};

fn read_username_from_file() -> Result<String, io::Error> {
    let mut f = File::open("hello.txt")?;
    let mut s = String::new();
    f.read_to_string(&mut s)?;
    Ok(s)
}

// 链式调用
fn read_username_from_file() -> Result<String, io::Error> {
    let mut s = String::new();
    File::open("hello.txt")?.read_to_string(&mut s)?;
    Ok(s)
}

18. 如何自定义错误类型？#

答案：

方法 1：使用 Box

use std::error::Error;
use std::fs::File;

fn main() -> Result<(), Box<dyn Error>> {
    let f = File::open("hello.txt")?;
    Ok(())
}

方法 2：自定义错误类型

use std::fmt;

#[derive(Debug)]
struct MyError {
    message: String,
}

impl fmt::Display for MyError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "{}", self.message)
    }
}

impl std::error::Error for MyError {}

fn might_fail() -> Result<i32, MyError> {
    Err(MyError {
        message: String::from("Something went wrong"),
    })
}

方法 3：使用 thiserror 或 anyhow

// Cargo.toml
// [dependencies]
// thiserror = "1.0"
// anyhow = "1.0"

use thiserror::Error;

#[derive(Error, Debug)]
enum MyError {
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
    #[error("Parse error: {0}")]
    Parse(#[from] std::num::ParseIntError),
}

并发编程#

19. Rust 的并发模型是什么？#

答案：

Rust 通过类型系统在编译时保证线程安全，主要使用线程和消息传递。

创建线程：

use std::thread;
use std::time::Duration;

fn main() {
    let handle = thread::spawn(|| {
        for i in 1..10 {
            println!("hi number {} from the spawned thread!", i);
            thread::sleep(Duration::from_millis(1));
        }
    });

    for i in 1..5 {
        println!("hi number {} from the main thread!", i);
        thread::sleep(Duration::from_millis(1));
    }

    handle.join().unwrap();
}

使用 move 闭包：

use std::thread;

fn main() {
    let v = vec![1, 2, 3];

    let handle = thread::spawn(move || {
        println!("Here's a vector: {:?}", v);
    });

    handle.join().unwrap();
}

20. 什么是消息传递（Message Passing）？#

答案：

Rust 使用 Channel 进行线程间通信，遵循"不要通过共享内存来通信，而是通过通信来共享内存"的理念。

使用 Channel：

use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();

    thread::spawn(move || {
        let val = String::from("hi");
        tx.send(val).unwrap();
    });

    let received = rx.recv().unwrap();
    println!("Got: {}", received);
}

多个发送者：

use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();
    let tx1 = tx.clone();

    thread::spawn(move || {
        let vals = vec![
            String::from("hi"),
            String::from("from"),
            String::from("the"),
            String::from("thread"),
        ];
        for val in vals {
            tx.send(val).unwrap();
            thread::sleep(Duration::from_secs(1));
        }
    });

    thread::spawn(move || {
        let vals = vec![
            String::from("more"),
            String::from("messages"),
            String::from("for"),
            String::from("you"),
        ];
        for val in vals {
            tx1.send(val).unwrap();
            thread::sleep(Duration::from_secs(1));
        }
    });

    for received in rx {
        println!("Got: {}", received);
    }
}

21. 什么是共享状态并发？#

答案：

虽然 Rust 推荐消息传递，但也支持通过共享内存进行并发。

使用 Mutex：

use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];

    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        let handle = thread::spawn(move || {
            let mut num = counter.lock().unwrap();
            *num += 1;
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    println!("Result: {}", *counter.lock().unwrap());
}

使用 RwLock（读写锁）：

use std::sync::{Arc, RwLock};
use std::thread;

fn main() {
    let data = Arc::new(RwLock::new(0));

    let mut handles = vec![];

    // 多个读锁
    for _ in 0..10 {
        let data = Arc::clone(&data);
        let handle = thread::spawn(move || {
            let reader = data.read().unwrap();
            println!("Read: {}", *reader);
        });
        handles.push(handle);
    }

    // 一个写锁
    let data = Arc::clone(&data);
    let handle = thread::spawn(move || {
        let mut writer = data.write().unwrap();
        *writer += 1;
    });
    handles.push(handle);

    for handle in handles {
        handle.join().unwrap();
    }
}

22. Send 和 Sync Trait 是什么？#

答案：

Send：

  • 允许在线程间转移所有权
  • 实现了 Send 的类型可以安全地发送到另一个线程

Sync：

  • 允许多线程访问
  • 实现了 Sync 的类型可以安全地在多个线程中共享引用

自动实现：

  • 大多数类型自动实现 Send 和 Sync
  • 原始类型（i32, bool 等）都实现了 Send 和 Sync
  • 由 Send 类型组成的类型自动实现 Send
  • 由 Sync 类型组成的类型自动实现 Sync

手动实现（不推荐）：

unsafe impl Send for MyStruct {}
unsafe impl Sync for MyStruct {}

异步编程#

23. Rust 的异步编程模型是什么？#

答案：

Rust 使用 async/await 语法进行异步编程，基于 Future trait。

基本语法：

use std::future::Future;

async fn hello() -> String {
    String::from("Hello, world!")
}

// async 函数返回 Future
fn main() {
    let future = hello();
    // 需要运行时执行
}

使用 Tokio：

// Cargo.toml
// [dependencies]
// tokio = { version = "1", features = ["full"] }

use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    println!("Hello");
    sleep(Duration::from_secs(1)).await;
    println!("World");
}

并发执行：

use tokio::time::{sleep, Duration};

async fn task1() {
    sleep(Duration::from_secs(1)).await;
    println!("Task 1");
}

async fn task2() {
    sleep(Duration::from_secs(1)).await;
    println!("Task 2");
}

#[tokio::main]
async fn main() {
    // 串行执行
    task1().await;
    task2().await;

    // 并发执行
    tokio::join!(task1(), task2());
    
    // 使用 spawn
    let handle1 = tokio::spawn(task1());
    let handle2 = tokio::spawn(task2());
    handle1.await.unwrap();
    handle2.await.unwrap();
}

24. Future 和 async/await 的关系？#

答案：

Future Trait：

trait Future {
    type Output;
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Self::Output>;
}

async/await 是语法糖：

// async 函数
async fn async_function() -> i32 {
    42
}

// 等价于
fn async_function() -> impl Future<Output = i32> {
    async {
        42
    }
}

手动实现 Future：

use std::future::Future;
use std::pin::Pin;
use std::task::{Context, Poll};

struct MyFuture {
    value: Option<i32>,
}

impl Future for MyFuture {
    type Output = i32;

    fn poll(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Self::Output> {
        if let Some(value) = self.value.take() {
            Poll::Ready(value)
        } else {
            Poll::Pending
        }
    }
}

宏系统#

25. 什么是宏（Macros）？#

答案：

宏是 Rust 的元编程工具，用于在编译时生成代码。

声明宏（Declarative Macros）：

macro_rules! vec {
    ( $( $x:expr ),* ) => {
        {
            let mut temp_vec = Vec::new();
            $(
                temp_vec.push($x);
            )*
            temp_vec
        }
    };
}

// 使用
let v = vec![1, 2, 3];

过程宏（Procedural Macros）：

// derive 宏
#[derive(Debug, Clone)]
struct Point {
    x: i32,
    y: i32,
}

// 属性宏
#[route(GET, "/")]
fn index() {}

// 函数式宏
println!("Hello, world!");

26. 如何编写自定义宏？#

答案：

声明宏示例：

macro_rules! my_vec {
    () => {
        Vec::new()
    };
    ($($x:expr),+ $(,)?) => {
        {
            let mut v = Vec::new();
            $(
                v.push($x);
            )+
            v
        }
    };
}

// 使用
let v = my_vec![1, 2, 3];

#[proc_macro_derive(HelloMacro)]

内存管理#

27. Rust 如何保证内存安全？#

答案：

Rust 通过所有权系统在编译时保证内存安全，无需垃圾回收。

机制：

  1. 所有权系统：每个值有唯一所有者
  2. 借用检查器：检查引用的有效性
  3. 生命周期检查：确保引用在使用期间有效
  4. 编译时检查：所有检查在编译时完成

对比其他语言：

  • C/C++：手动管理，容易出错
  • Java/Python：垃圾回收，运行时开销
  • Rust：编译时检查，零运行时开销

28. 什么是智能指针？#

答案：

智能指针是拥有额外功能的指针，Rust 标准库提供了多种智能指针。

Box：

// 在堆上分配
let b = Box::new(5);
println!("b = {}", b);

Rc（引用计数）：

use std::rc::Rc;

let a = Rc::new(5);
let b = Rc::clone(&a);
let c = Rc::clone(&a);
// a, b, c 都指向同一个值

RefCell（内部可变性）：

use std::cell::RefCell;

let data = RefCell::new(5);
{
    let mut borrow = data.borrow_mut();
    *borrow += 1;
}
println!("{}", data.borrow());

组合使用：

use std::rc::Rc;
use std::cell::RefCell;

let value = Rc::new(RefCell::new(5));
let a = Rc::clone(&value);
let b = Rc::clone(&value);

*a.borrow_mut() += 10;
*b.borrow_mut() += 20;

println!("value = {:?}", value);

性能优化#

29. 如何优化 Rust 程序性能？#

答案：

1. 使用 release 模式编译

cargo build --release

2. 避免不必要的克隆

// 不好
fn process(data: Vec<i32>) {
    let data2 = data.clone();
    // ...
}

// 好
fn process(data: &Vec<i32>) {
    // ...
}

3. 使用迭代器

// 不好
let mut result = Vec::new();
for item in items {
    if item > 0 {
        result.push(item * 2);
    }
}

// 好
let result: Vec<_> = items
    .iter()
    .filter(|&x| *x > 0)
    .map(|x| x * 2)
    .collect();

4. 使用零成本抽象

// Option 和 Result 在运行时没有开销
let value = Some(5);
match value {
    Some(x) => println!("{}", x),
    None => {}
}

5. 使用内联

#[inline]
fn fast_function(x: i32) -> i32 {
    x * 2
}

6. 避免动态分发

// 动态分发（慢）
fn process(t: &dyn Trait) {}

// 静态分发（快）
fn process<T: Trait>(t: &T) {}

30. 如何分析 Rust 程序性能？#

答案：

使用 cargo bench：

// Cargo.toml
// [dev-dependencies]
// criterion = "0.5"

use criterion::{black_box, criterion_group, criterion_main, Criterion};

fn fibonacci(n: u64) -> u64 {
    match n {
        0 => 1,
        1 => 1,
        n => fibonacci(n-1) + fibonacci(n-2),
    }
}

fn criterion_benchmark(c: &mut Criterion) {
    c.bench_function("fib 20", |b| b.iter(|| fibonacci(black_box(20))));
}

criterion_group!(benches, criterion_benchmark);
criterion_main!(benches);

使用 perf（Linux）：

perf record ./target/release/my_program
perf report

使用火焰图：

cargo install flamegraph
cargo flamegraph

32. 常见陷阱和如何避免#

答案：

1. 循环中的借用

// 错误
let mut vec = vec![1, 2, 3];
for item in &vec {
    vec.push(item * 2); // 错误：不能同时有可变和不可变借用
}

// 正确
let vec = vec![1, 2, 3];
let new_vec: Vec<_> = vec.iter().map(|x| x * 2).collect();

2. 移动后使用

// 错误
let s = String::from("hello");
let s2 = s;
println!("{}", s); // 错误：s 已被移动

// 正确
let s = String::from("hello");
let s2 = s.clone();
println!("{}", s);

3. 悬垂引用

// 错误
fn dangle() -> &String {
    let s = String::from("hello");
    &s // 错误：返回悬垂引用
}

// 正确
fn no_dangle() -> String {
    let s = String::from("hello");
    s
}

4. 忘记处理错误

// 不好
let file = File::open("hello.txt").unwrap();

// 好
match File::open("hello.txt") {
    Ok(file) => {
        // 处理文件
    }
    Err(e) => {
        eprintln!("Error opening file: {}", e);
    }
}

Rust 是一门强大的系统编程语言，通过所有权系统在编译时保证内存安全，同时提供接近 C/C++ 的性能。掌握 Rust 需要理解：

  4. 错误处理：Result 和 Option

  6. 异步编程：Future、async/await

Rust 的学习曲线较陡，但一旦掌握，可以编写出安全、高效的系统级代码。
