## 项目细节

以下为本人近年负责的核心平台、基础设施与智能合约项目的技术附录，可按需观看：

### L2 节点激励网络

**项目角色：** 技术负责人/架构设计/核心研发  
**技术堆栈：** Hardhat、Solidity、Openzepplin、ERC721、IPFS、ERC4907、EIP712、Go、SQLite、AES、Redis、Lua、MongoDB、SQLite、Docker、ECS  
**项目周期：** 2024.12 – 2025.07

**项目描述：**

把L2节点销售转化为业务模型，从 L2节点凭证 → 节点客户端 → 运行行为证明 → 链下激励结算 → 链上合约领取 → Portal交互模型 全链路完成 L2 节点网络激励系统的架构设计与交付，实现节点收益模型的长期可执行、可追溯与可审计。

**核心工作与技术实现：**

* **节点资产凭证与委托模型设计：** 设计并实现 MuseNodeLicense(ERC721 + ERC4907)节点 NFT，解耦节点"所有权"与"运行权"，支撑用户自运行与第三方托管运行的商业模式。
* **链上激励与收益释放合约：** 设计并实现 MuseNodeReward 合约，基于 EIP-712 签名 + Nonce 防重放机制，支持初始空投、运行激励领取与锁仓提现的可审计领取模型。
* **节点客户端核心架构：** 从 0 到 1 设计并实现 Go 跨平台节点客户端，覆盖设备指纹生成、节点钱包生成/复用、SQLite本地AES加解密、签名心跳与委托状态同步、快捷命令。
* **L2 运行证明与链下追踪体系：** 节点客户端对接 L2 RPC 与 Tracker 服务，通过私钥签名注册与心跳，实现节点真实运行行为的可信映射。
* **节点运行结算中枢(Tracker)：** 构建NFT委托索引、节点注册、心跳校验、在线统计与奖励聚合体系，按小时结算节点收益并落库，作为链上领取的唯一可信数据源。
* **Portal 节点资产管理体系：** 基于 Tracker 数据构建钱包登入、KYC、NFT 委托管理、初始空投领取、分段收益提现与节点监控仪表盘的完整资产管理闭环。
* **高并发心跳性能治理：** 重构原多次 Redis IO 锁为 Lua 原子锁模型，将心跳响应从 10s+ 优化至 <0.5s，P95 控制在 0.1s 内，彻底消除在线超时问题。

**项目成果：**

* 支撑节点收益承诺的工程化兑现，保障节点激励的长期可释放、可追溯与可审计执行。
* 系统上线半年稳定运行，持续支撑 5000+ 节点 长期在线(用户自运行 + 第三方托管)，期间 0 异常奖励、0 资产事故。
* 系统已支撑3967 个地址完成节点初始权益领取，累计释放 83W+ MORE 激励，完成 4231 次提现，保障了用户资产与平台资产的双向安全。

### Web3 游戏商城体系(生态级支付协议)

**项目角色：** 架构设计 / 任务拆分 / 合约研发  
**技术堆栈：** Hardhat、Solidity、Openzepplin、EIP712、Typescript、NextJS、Golang、Gin、Gorm、Redis、MongoDB、Docker、K8S、AWS  
**项目周期：** 2024.09 – 2024.12

**项目描述：**

在多款移动端游戏已集成 Web2 商城的基础上，从 0 到 1 设计并落地 Web3 游戏商城体系，打通"用户身份 → 链上支付 → 订单确认 → 游戏道具下发"的完整闭环，构建跨游戏复用的统一Web3 支付协议。

**核心工作与技术实现：**

* **统一身份与安全传递：** 基于平台 OAuth2 设计一次性授权码(One-time Auth Code)机制，完成游戏客户端到 Web3 商城的安全身份迁移，防止 Token 泄露、复用与劫持风险。
* **多代币支付与价格模型：** 设计多代币支付模型(可扩展任意代币)，集成 CoinGecko 周期拉取汇率，支持周期报价机制(X 分钟内价格锁定)，抽象 Payment Adapter 层支持多链与新代币的配置化扩展。
* **订单流与防重放机制：** 基于 EIP712 设计链下授权支付模型，引入全局 requestId + 链下状态机，防止重复支付、价格篡改与订单重放。
* **异步通知与最终一致性：** 设计"链上确认 → 商城签名通知 → 游戏服幂等下发 → 失败补偿重试"的可靠通知链路，保障支付与道具发放的最终一致性。
* **跨游戏标准化接入协议：** 输出完整 Web3 商城接入规范(OAuth 授权、跳转协议、JWT 通知、幂等处理、异常补偿)，实现多游戏零重复开发接入。

**项目成果：**

* 支撑生态 3 款移动端游戏接入(持续扩展中)，是生态统一的 Web3 渠道支付标准。
* 支撑游戏公测 2 次，累计处理 27000+ 次 Web3 商城购买请求，0 双花、0 资产异常、0 道具发放事故。
